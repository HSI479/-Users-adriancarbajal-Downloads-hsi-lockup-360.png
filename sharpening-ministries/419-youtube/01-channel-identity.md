# 4:19 Podcast — channel identity

## Handle

**Recommendation: `@419podcast` if it is free; otherwise `@the419podcast`.**

| Candidate | Verdict | Why |
|---|---|---|
| `@419podcast` | First choice | Exactly the channel name, shortest to say on air and print on a QR card. YouTube offers it automatically when the channel is named "4:19 Podcast". |
| `@the419podcast` | Fallback | Same searchability, one extra word. Fine if the first is taken. |
| `@fourninteenpodcast` | Avoid | Misspelled ("ninteen"). Even spelled right, `@fournineteenpodcast` is 20 characters nobody will type from a spoken plug. |

**Live availability could not be verified from this session** (youtube.com is blocked by the
sandbox's network policy). What the open web did show:

- `@419-podcast` (with a hyphen) is already taken by a Ukrainian cannabis-culture channel named
  "Подкаст 4:19". It will sit next to ours in search for "4:19 podcast". That is a reason to lock the
  hyphen-free handle quickly and to lean on the Sharpening Ministries name in the channel name's
  neighbors (banner, About, descriptions) so there is no confusion.
- "Four Hundred & Nineteen" (a Toledo, Ohio radio show) uses `/419podcast` on Spotify for Creators.
  Different platform, no conflict on YouTube, but expect some "419 area code" noise in search.

**30-second check on launch day (desktop):** open `youtube.com/@419podcast` in a private window. A
"This page isn't available" message means it is free. Then YouTube Studio → Customization → Basic
info → Handle → type it; Studio says "Handle is available" or not. Handles can be changed twice per
14 days, so a mistake is recoverable. Channel names can be changed 3 times per 90 days.

Also reserve the same handle on Instagram, TikTok, Facebook and X the same day, even if unused.

## Channel name

**4:19 Podcast**

(Sharpening Ministries appears in the banner tagline, the About text, the links block and the first
two lines of every description, so a search for the ministry still lands here.)

## About / channel description

Studio → Customization → Basic info → Description. Limit is 1,000 characters; this is 740.

```
The 4:19 Podcast is a conversation for men who want to walk with Jesus for a lifetime, not a season.

Named for Matthew 4:19 ("Follow me, and I will make you fishers of men"), the show is produced by Sharpening Ministries and hosted by founder Larry Watkins with Adrian Carbajal. Each episode sits down with men who are living it out: guests who have built something for the Kingdom, and ordinary men talking honestly about what discipleship looks like six months, six years and sixty years in.

New episodes every week. Clips and shorts between episodes.

Sharpening Ministries exists to help men walk for a lifetime. Learn more, find a men's weekend, or get in touch at sharpeningministries.com.

Stay sharp, stay strong, stay courageous.
```

Short version for places with a 150-character cap (Shorts, social bios):

```
Men walking with Jesus for a lifetime. A Sharpening Ministries podcast with Larry Watkins. New episodes weekly. sharpeningministries.com
```

## Links block (Studio → Customization → Basic info → Links)

Up to 14 links; the first one is shown as a button on the channel header. Order:

1. **Sharpening Ministries** → `https://sharpeningministries.com`
2. **Men's weekends / events** → the events page on the site (confirm URL)
3. **Listen on Spotify** → add when the audio feed exists
4. **Listen on Apple Podcasts** → add when the audio feed exists
5. **Instagram** → ministry account (confirm handle)
6. **Facebook** → ministry page (confirm)
7. **Give / support** → only if the ministry wants it public on YouTube (confirm with Larry)

Links in this block do not need the YouTube Partner Program, unlike end-screen and card links
(see the launch plan). The website link is also pinned as a comment on every episode.

## Other Studio basics to set on day one

- **Contact email** (Basic info): a ministry address, not a personal one (e.g. `podcast@sharpeningministries.com`).
- **Keywords** (Settings → Channel → Basic info): `4:19 Podcast, Sharpening Ministries, Larry Watkins, men's discipleship, Christian men, men's ministry, Matthew 4:19, fishers of men, Christian podcast, [city/state, confirm]`
- **Country of residence**: United States.
- **Audience** (Settings → Channel → Advanced): "No, set this channel as not made for kids."
- **Default upload settings** (Settings → Upload defaults): paste the description template from the
  launch plan, set visibility Private, license Standard, category People & Blogs, comments
  "Hold potentially inappropriate comments for review", tags `4:19 Podcast, Sharpening Ministries`.
- **Watermark** (Customization → Branding → Video watermark): the medallion (profile image), shown
  "Entire video". It is a subscribe button on desktop.
- **Channel trailer**: the 16:9 logo sting plus a 45–60 s montage from the three episodes; set in
  Customization → Layout → Video spotlight → "Channel trailer for people who haven't subscribed".
