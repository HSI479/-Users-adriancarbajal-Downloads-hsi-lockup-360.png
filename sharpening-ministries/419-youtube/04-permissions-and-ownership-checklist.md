# 4:19 Podcast — permissions and ownership checklist

Decided: the long-term Primary Owner of both channels is `media@sharpeningministries.com`
(see `05-accounts-and-channel-structure.md`). **If `media@` exists before launch day, create the
channels signed in as `media@` and skip section B entirely.** The two run-throughs below cover the
fallback: **launch day** (channel creation under Adrian's Google account) and **handoff day**
(Primary Owner moves to `media@`, at least 7 days later). Everything here
is done in a **desktop browser**; Brand Account ownership changes are not available in the apps.

Create the channel as a Brand Account:

- [ ] Basic info: description, links block, contact email, keywords, audience "not made for kids".

- [ ] Studio → Settings → Permissions: confirm Larry shows as Owner, Michael as Editor, nobody unexpected.
- [ ] Settings → Channel → Feature eligibility: still shows phone verified (verification stays with the channel).
- [ ] Change the contact email in Basic info to the ministry address if it still shows Adrian's.
- [ ] Studio → Settings → Channel → Advanced settings: check "Manage YouTube account" and
      the linked AdSense (none at launch; if monetization is ever enabled it must be the ministry's AdSense).
- [ ] Update the table below.

## C. Recovery and hygiene

- Never share passwords; roles replace that. If a login must be shared for a studio machine, it is
  the Editor-level ministry account, never the Primary Owner.
- Remove a role the day someone leaves the team.
- Before any ownership change, download a copy of the channel's data once (Google Takeout →
  YouTube) so titles, descriptions and chapters exist outside YouTube.
- Keep this file current; it is the record of who can do what.
